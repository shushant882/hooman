
# 🐾 Hooman – The Pet Parenting App

### 🧠 Overview

**Hooman** is an all-in-one **pet parenting app** designed to make life easier for pet owners. It helps users manage pet health, track daily activities, access vet care, and connect with a growing pet-loving community — all in one place.

This project showcases modern **Android development practices** using **Kotlin**, **Jetpack Compose**, and **Firebase**.

---

### 🚀 Features

* 🐶 **Pet Profile Management** – Add, edit, and view detailed pet profiles.
* 🕒 **Activity Tracking** – Track walks, meals, and appointments easily.
* 💉 **Health Records** – Store and manage vaccination and medical data.
* 🔔 **Reminders & Notifications** – Get alerts for feeding, walks, or vet visits.
* ☁️ **Firebase Integration** – Real-time database and authentication.
* 🌐 **API Integration** – Connects seamlessly with backend services.
* 🧭 **Modern UI** – Built entirely with **Jetpack Compose** for a smooth and responsive experience.

### 🧪 Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/HoomanApp.git
   ```
2. Open the project in **Android Studio (Arctic Fox or newer)**.
3. Sync Gradle and install dependencies.
4. Add your **Firebase configuration file (`google-services.json`)** in the `app/` directory.
5. Run the app on an emulator or connected device.
